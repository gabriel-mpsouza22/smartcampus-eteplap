SMARTCAMPUS — MOCK DATA ETEPLAP

1. INSTALAÇÃO

Use o arquivo:
instalador/config_eteplap.json

A partir da pasta instalador, em Windows:
python build_exe.py --config config_eteplap.json

O config_eteplap.json controla somente a instalação. Ele não controla a massa de dados de demonstração.

2. INICIALIZAÇÃO AUTOMÁTICA DO MOCK DATA

Na primeira abertura do .exe, depois da configuração feita pelo instalador, o
launcher cria a estrutura persistente:

    <pasta do .exe>/
      core/config.json
      core/.secret_key
      sceds/data/
      sceds/manifest.json
      sceds/.mock_initialized

Em seguida, gerar_mock_data.py é executado automaticamente e cria uma massa
relacional completa para demonstração. O processo só grava o marcador
.mock_initialized depois de concluir com sucesso.

Para reconstruir a massa manualmente, ainda é possível executar:

    python gerar_mock_data.py

ou chamar o módulo com a pasta da instalação. Cada reconstrução gera dados
novos, sem seed fixa.

O script reconstrói os dados de demonstração das tabelas utilizadas pelos módulos contratados, evitando duplicação em execuções repetidas.

3. MÓDULOS COM DADOS

A massa cobre os módulos persistentes do projeto:

- Cadastro de Alunos
- Controle de Pontualidade
- Agendamento de Recursos
- Biblioteca
- Secretaria e Portaria
- Ocorrências
- Prevenção de Evasão
- Controle de Chaves
- Monitoramento
- Chamados Técnicos
- IoT
- Saída de Alunos
- Controle de Visitantes

O Sinal não possui uma tabela SCEDS própria; seus arquivos de configuração
continuam sendo empacotados pelo instalador.

4. PERFIL DA MASSA

A massa representa a ETEPLAP com aproximadamente 35–40 alunos por turma, 12 turmas, 10 professores e funcionários administrativos de secretaria, portaria, biblioteca e coordenação.

Os dados são relacionados: frequência, atrasos, ocorrências, empréstimos e sinais de evasão são produzidos a partir de perfis comportamentais coerentes. Professores também fazem reservas de recursos e retiradas de chaves.

O período simulado é de fevereiro de 2026 até 26/08/2026.
